# Governance

## Project Structure

Sampati is an open-source compliance automation platform built for India's regulators.

### Repositories

- **sampati-sdk** (MIT) — Plugin SDK, schemas, protocol
- **sampati** (Apache-2.0) — Community Edition core platform
- **sampati-enterprise** (PCL, private) — Enterprise extensions

### Maintainers

- **PragneshKumar S. Singh** — Co-Founder & CTO, VayuX Systems LLP (Project Lead)

### Decision Making

- Technical decisions: Maintainer proposes, community discusses, maintainer decides
- Security-critical decisions: Require expert review
- Legal/regulatory decisions: Require counsel review
- Licence changes: Require explicit approval from all copyright holders

### Release Process

- Monthly minor releases for Community Edition
- Security patches for latest two minor versions
- Enterprise Edition released after each Community Edition minor

### Community

- Pack maintainers for each country pack
- Connector maintainers for first-party connectors
- Partner firms (CA/CS, auditors) invited to review packs
